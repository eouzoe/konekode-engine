# Konekode 學習引擎

Konekode 貓貓競程的學習系統本身：知識結構、評估學生現在在哪個狀態、掌握與遺忘、能力、下一步做什麼。網站、畫面、美術在另一個倉庫，只透過這裡編出來的 WebAssembly 呼叫引擎。

## 它做什麼

- 從內容（題目、標準解、單元）算出知識結構：語法的構造來自編譯器的語法樹，編輯操作來自編輯規則，題目需要的技能來自哪一份解過哪些子題組。
- 從一份只增不改的事件，算出學生的狀態：會什麼、有多確定、還記得多少、各項能力到哪。
- 回答下一步做什麼、該複習什麼，以及每一個判斷的依據。

## 原則

- 一個學生、沒有任何資料時就要好用；用他自己的紀錄越來越好。
- 純函式、不讀時鐘、可以重播；換裝置重算結果一致。
- 結構是算出來的，不手寫對照表。

## 現在有什麼

- `konekode-space`：學習空間。規則寫成「會了這些就能學這個」，可以有好幾種「這些」；算出哪些是合法的狀態、現在能學什麼（外緣）、剛學會什麼（內緣）、從某個狀態到某一格還差哪些、只看一部分時的樣子（投影）；以及技能與題目的對照（一題可以有好幾組技能）。
- `konekode-assess`：從作答判斷學生在哪個狀態。在合法的狀態上維持機率，每一筆作答照「會了卻答錯」「不會卻答對」兩個機率更新；這兩個機率依作答的條件而不同，示範不算證據；下一題挑答對答錯最難猜的那一題。

現有網站裡的引擎會一塊一塊搬過來。

需要 [devenv](https://devenv.sh)。

